Machine learning is a subfield of artificial intelligence focused on building systems that learn patterns from data rather than following explicit rules. A typical machine learning workflow involves collecting data, cleaning it, choosing a model, training the model, and evaluating its performance. Common categories of machine learning include supervised learning, unsupervised learning, and reinforcement learning. Python programming is the most widely used language for machine learning research and production because of libraries like TensorFlow and PyTorch. Machine learning models rely heavily on data structures such as vectors, matrices, and tensors, and on algorithms like gradient descent to minimize error during training.
