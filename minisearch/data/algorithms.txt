An algorithm is a precise, step by step procedure for solving a problem or completing a task. Search algorithms, sorting algorithms, and graph algorithms are core topics in computer science education. Depth first search, often abbreviated DFS, explores as far as possible along each branch before backtracking, and it is commonly used to traverse trees and tries, collecting every complete word reachable from a given prefix. Efficient algorithms often depend on well chosen data structures, such as using a hash table for constant time average lookup or a trie for fast prefix based autocomplete. Ranking algorithms in search engines commonly score documents using word frequency, giving higher scores to documents where query terms appear more often.
